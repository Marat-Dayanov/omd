# Финальный проект

## Зависимости

Библиотеки, необходимые для запуска проекта, перечислены в файле requirements.txt.
Для установки откройте в терминале папку final_project и воспользуйтесь командой:
```pip install -r requirements.txt```

## Запуск

Откройте laureates_countries_task.ipynb в любом удобном для вас редакторе.
